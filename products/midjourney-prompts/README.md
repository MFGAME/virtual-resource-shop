## ⭐ 精选示例

### 示例1: 电影级人像

```
Portrait of a young woman with emerald green eyes, soft natural lighting, shallow depth of field, shot on Sony A7R IV, 85mm lens, f/1.4, ultra realistic skin texture, subtle makeup, wind-blown hair, golden hour, cinematic color grading --ar 4:5 --v 5.2 --style raw
```

**关键词解析：**
- `emerald green eyes` - 翡翠绿眼睛（具体特征）
- `shallow depth of field` - 浅景深（背景虚化）
- `85mm lens, f/1.4` - 镜头参数（专业人像镜头）
- `golden hour` - 黄金时刻（最佳光线）
- `--ar 4:5` - 纵向人像比例
- `--style raw` - 原始风格（更真实）


**关键词解析：**
- `neon lights reflecting on wet streets` - 霓虹灯在湿润街道反射

## 🛠️ 进阶技巧

### 1. 参数详解

```
--ar X:Y     # 宽高比（如16:9, 4:5, 1:1）
--v 5.2      # Midjourney版本
--style raw  # 更真实的风格
--q 2        # 更高质量（消耗更多快速时间）
--s 750      # 风格化程度（0-1000）
--c 50       # 混乱度/多样性（0-100）
--seed 12345 # 固定种子（可复现结果）
```

### 2. 负向提示词

```
--no text, watermark, blurry, low quality, deformed, ugly
```

### 3. 权重控制

```
red::2 blue::1  # 红色权重是蓝色的2倍
```

### 4. 图生图

```
[图片URL] 描述文字 --iw 0.5
# iw = image weight，0-2，越大原图影响越大
```
