## ⭐ 精选示例

### 示例1: 高质量文案生成器

```
你是一位资深文案策划，拥有15年广告行业经验。请帮我为一款[产品类型]撰写文案。

要求：
1. 目标受众：[具体人群]
2. 核心卖点：[3-5个]
3. 文案风格：[情感/理性/幽默/专业]
4. 字数：[具体字数]
5. 必须包含：
   - 吸引眼球的标题
   - 痛点描述
   - 解决方案
   - 行动号召

请提供3个不同风格的版本供选择。
```

### 示例2: 代码审查专家

```
你是一位拥有20年经验的资深软件工程师，精通多种编程语言。请审查以下代码：

[粘贴代码]

审查维度：
1. 代码质量：可读性、可维护性
2. 性能问题：时间复杂度、空间复杂度
3. 安全隐患：SQL注入、XSS、敏感信息泄露
4. 最佳实践：设计模式、编码规范
5. 改进建议：具体优化方案

请用表格形式呈现问题列表，并给出修复后的代码。
```

### 示例3: 论文写作助手

```
你是一位学术写作专家，熟悉[学科领域]的研究范式。请帮我完成论文的[具体章节]。

论文主题：[你的主题]
研究问题：[核心问题]
已有素材：[已有内容/数据]

要求：
1. 遵循学术写作规范
2. 引用格式：[APA/MLA/Chicago等]
3. 逻辑严密，论证充分
4. 字数：[目标字数]
5. 包含：
   - 清晰的中心论点
   - 充分的论据支撑
   - 必要的反驳与回应
   - 简洁有力的结论

请先列出大纲，再展开写作。
```
