## 文案创作

### 产品文案生成器

```
你是一位顶级文案策划，曾为Apple、Nike等品牌撰写文案。

产品信息：
- 名称：[产品名]
- 类型：[产品类型]
- 核心卖点：[3-5个卖点]
- 目标用户：[用户画像]
- 价格区间：[价格]

请创作3个版本的文案：
1. 情感版（走心、讲故事）
2. 理性版（数据、功能）
3. 幽默版（轻松、有趣）

每个版本包含：
- 标题（不超过20字）
- 正文（100-200字）
- Slogan（不超过10字）

要求：避免陈词滥调，用具体细节打动人心。
```

### 爆款标题生成器

```
你是一位新媒体运营专家，擅长写出10万+阅读的标题。

文章主题：[主题]
核心内容：[简述内容]
目标受众：[受众]
平台：[公众号/小红书/抖音等]

请生成20个标题，覆盖以下类型：
1. 数字型（如"3个技巧"）
2. 提问型（引发好奇）
3. 对比型（A vs B）
4. 情感型（引发共鸣）
5. 利益型（明确价值）
6. 蹭热点型（结合时事）
7. 反常识型（打破认知）
8. 故事型（设置悬念）

每个标题标注类型，并说明为什么有效。
```

### 小红书种草文案

```
你是一位小红书达人，擅长写出高转化率的种草笔记。

产品：[产品名称]
类型：[美妆/穿搭/美食/数码等]
核心卖点：[3-5个]
使用感受：[真实体验描述]
价格：[价格]

请创作一篇小红书笔记，包含：
1. 标题：带emoji，不超过20字
2. 正文：
   - 开头：制造场景感/痛点
   - 中间：产品介绍+使用体验
   - 结尾：总结+行动号召
   - 适当使用emoji
   - 分段清晰
3. 标签：10个相关标签

风格：真实、接地气、像闺蜜分享
字数：300-500字
```

## 内容营销

### 公众号文章大纲

```
你是一位资深内容运营，擅长策划高传播的文章。

文章主题：[主题]
目标受众：[受众画像]
核心观点：[你要表达什么]
文章目的：[教育/娱乐/转化等]

请生成文章大纲，包含：
1. 标题备选（5个）
2. 开头设计（3种方案）
   - 故事开场
   - 数据开场
   - 提问开场
3. 正文结构
   - 3-5个核心小标题
   - 每个小标题下的关键点
   - 案例/数据支撑
4. 结尾设计
   - 总结回顾
   - 行动号召
5. 金句预埋（3-5个可在文中/结尾使用的金句）

要求：逻辑清晰，层层递进，有共鸣。
```

### 视频脚本生成

```
你是一位短视频脚本策划，熟悉抖音/B站的内容调性。

视频主题：[主题]
视频类型：[知识科普/剧情/测评/Vlog等]
时长：[秒数]
目标数据：[播放量/点赞/评论目标]

请生成完整脚本，包含：
1. 视频标题
2. 封面文案
3. 前3秒钩子（抓住注意力）
4. 完整脚本（标注场景/镜头/台词）
   - 画面描述
   - 台词/旁白
   - 字幕要点
   - BGM建议
5. 结尾设计（引导互动）
6. 发布策略
   - 最佳发布时间
   - 标签推荐
   - 评论区预埋问题

节奏要求：紧凑，每3秒一个信息点
```

## 小说创作

### 小说大纲生成

```
你是一位畅销书作家，擅长构思引人入胜的故事。

小说类型：[玄幻/都市/言情/悬疑等]
核心创意：[你的创意点]
目标读者：[读者画像]
预计字数：[字数]

请生成小说大纲：
1. 一句话梗概（不超过50字）
2. 核心设定
   - 世界观（如适用）
   - 力量体系（如适用）
   - 特殊设定
3. 主要人物（3-5个）
   - 姓名、性格、背景、动机
   - 人物关系图
4. 故事结构
   - 开端（铺垫、激励事件）
   - 发展（冲突升级）
   - 高潮（核心冲突）
   - 结局（问题解决）
5. 前10章细纲（每章200字概述）
6. 核心冲突点设计
7. 伏笔埋设计划

要求：情节紧凑，人物立体，有情感共鸣。
```

### 章节写作

```
你是一位小说作家，请根据以下信息续写章节：

前文提要：[前一章发生了什么]
本章目标：[本章要达成什么]
关键事件：[必须发生的事件]
出场人物：[人物列表]
情感基调：[紧张/温馨/热血等]

要求：
1. 字数：[2000-5000字]
2. 风格：[具体风格描述]
3. 包含：
   - 环境描写
   - 人物对话
   - 心理活动
   - 冲突/转折
4. 避免陈词滥调
5. 结尾留钩子（引向下一章）

请直接开始写作，不要解释。
```

## 商务写作

### 商业计划书

```
你是一位资深商业顾问，帮助过多家创业公司完成融资。

项目信息：
- 项目名称：[名称]
- 所在行业：[行业]
- 核心产品/服务：[描述]
- 目标市场：[市场描述]
- 团队情况：[简述]

请帮我撰写商业计划书，包含以下章节：
1. 执行摘要（1页）
2. 公司介绍
3. 市场分析
   - 市场规模
   - 目标用户
   - 竞争分析
4. 产品/服务介绍
5. 商业模式
6. 运营计划
7. 财务预测（3年）
8. 融资需求
9. 团队介绍
10. 风险分析

每个章节提供：
- 核心要点
- 具体内容（200-500字）
- 数据/图表建议

风格：专业、数据驱动、有说服力
```

### 商务邮件

```
你是一位商务沟通专家，请帮我撰写一封商务邮件。

邮件目的：[目的：约见/报价/投诉/感谢等]
收件人：[对方身份/职位]
发件人：[我的身份]
背景信息：[简要说明背景]

要求：
1. 主题行（不超过50字，明确目的）
2. 称呼（得体）
3. 开头（说明来意）
4. 正文（清晰表达核心内容）
5. 结尾（行动号召/下一步）
6. 落款

语气：[正式/友好/强硬等]
长度：简洁，不超过[字数]

请提供3个版本：
- 版本A：正式版
- 版本B：友好版
- 版本C：简洁版
```

## 学术写作

### 论文大纲

```
你是一位学术写作专家，熟悉[学科]的研究范式。

论文主题：[主题]
研究问题：[核心问题]
研究方法：[定量/定性/混合等]
字数要求：[字数]

请生成论文大纲：
1. 标题（3个备选）
2. 摘要框架（200-300字）
3. 引言结构
   - 研究背景
   - 研究问题
   - 研究意义
   - 论文结构
4. 文献综述结构
   - 主题分类
   - 关键文献清单
5. 研究方法章节
6. 结果/分析章节
7. 讨论章节
8. 结论章节
9. 参考文献（建议格式）

引用风格：[APA/MLA/Chicago等]
```

### 文献综述

```
你是一位学术研究专家，请帮我撰写文献综述。

研究主题：[主题]
学科领域：[学科]
时间范围：[年份范围]
文献数量：[已阅读的文献数]

已有文献列表：
[列出主要文献]

请撰写文献综述，包含：
1. 引言（说明综述范围和目的）
2. 主题1：[主题名称]
   - 核心观点
   - 代表文献
   - 研究发现
   - 研究不足
3. 主题2：...
4. 主题3：...
5. 研究趋势分析
6. 研究空白识别
7. 未来研究方向
8. 总结

要求：
- 批判性分析，不是简单罗列
- 指出不同研究的矛盾点
- 识别研究空白
- 字数：[字数]

引用格式：[APA/MLA等]
```

## 使用技巧

1. **提供具体信息**：越具体的输入，输出越精准
2. **指定风格语气**：明确你想要的写作风格
3. **迭代优化**：生成后可以要求"更..."、"加入..."
4. **组合使用**：先用大纲Prompt，再用具体写作Prompt
5. **保持人设**：在长篇创作中，定期提醒AI保持人物/风格一致
